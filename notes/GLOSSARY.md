# Glossary

Plain-English definitions for every acronym and term used in this repo and in our research.

## Tasks

| Term | Stands for | Plain meaning |
|---|---|---|
| **STT** | speech-to-text | transcribe audio into written words |
| **TTS** | text-to-speech | synthesize spoken audio from written words |
| **STS** | speech-to-speech | transform one voice into another (voice conversion); the future voice-cloning path |
| **LM** | language model | a model of which text is likely; we run *without* one (greedy decode) so scores reflect the acoustic model alone |

## Training

| Term | Stands for | Plain meaning |
|---|---|---|
| **parameters** | — | the model's adjustable numbers ("knobs"); ours has ~1.2M, Parakeet has 600M |
| **step** | — | one update cycle: guess → score → adjust all knobs a tiny amount |
| **batch** | — | the handful of examples processed together in one step (8 on the Mac, 24 on the 4090) |
| **epoch** | — | one full pass through the training dataset |
| **loss** | — | one number measuring how wrong the current guesses are; training exists to push it down |
| **gradient** | — | for every knob, which direction (and how strongly) to turn it to reduce the loss |
| **grad norm** | gradient norm | the overall size of the adjustment; huge values = training is unstable |
| **clipping** | gradient clipping | cap the adjustment size so one bad step can't wreck the model |
| **LR** | learning rate | how far each knob turns per step; too high explodes, too low crawls |
| **warmup / cosine schedule** | — | start with a tiny LR, ramp up, then glide down smoothly over the run |
| **AdamW** | — | the standard optimizer (the algorithm that applies gradients), with weight decay |
| **weight decay** | — | gentle pull of knobs toward zero; a regularizer (we exempt the physics params) |
| **overfit** | — | memorizing training examples instead of learning general rules — bad in production, but our *smoke gates* overfit 10 clips on purpose to prove the machinery works |
| **underfitting** | — | the opposite failure: the model lacks the capacity, objective, or training to fit even its *training* data. Diagnosis: train score ≈ val score, both mediocre (our K0 runs: ~1.29 vs ~1.30). The fix is a better objective/architecture/longer training — **not** more data |
| **validation** | — | scoring on held-out examples the model never trained on; the honest number |
| **checkpoint** | — | a saved snapshot of all parameters (`last.pt`, `best.pt`); `--resume` continues from one |
| **BPTT** | backpropagation through time | computing gradients backwards through every timestep of a recurrent model |
| **TBPTT** | truncated BPTT | only propagate gradients back N frames (we use 64) so they can't snowball over long audio |
| **NaN** | not-a-number | numeric blow-up; the trainer detects and skips such steps |
| **frozen** | — | excluded from training: the parameters stay exactly as they are (gradients never touch them, the optimizer skips them) while everything around them trains normally. "Frozen physics" (F-019) = K and ω left at random init while bookends train — the reservoir test; "frozen Vocos" = the pretrained vocoder used as-is; staged assembly freezes the pretrained core while bookends train against it. Second sense in our methodology: "frozen controls" = recorded control curves/checkpoints kept as fixed comparison artifacts so core-only experiments don't re-run them |
| **seed** | random seed | the single integer that initializes the random-number generator, determining every "random" choice in a run: initial kernel/ω values, the phase field's starting state, data shuffling order. Same seed + same code = bit-identical rerun (why every training log records command + commit + seed); *different* seeds = independent repeats — "0.998/0.996/0.992 across seeds" means the same experiment run three times from different random starts all landed close, so the result isn't luck ("seed-robust") |
| **protocol n / gate-n** | — | the two clip-count sizes a cell can run at: **protocol n** (2,048 train / 512 test clips) is the full standard every matrix cell uses — bars and verdicts are judged ONLY at this size; **gate-n** (512/128) is the quarter-cost reduced size for calibration gates and probes — good for picking operating points, never scored evidence. The ridge probe is the only learner, so more clips = a stronger readout: an effect can be real at gate-n yet vanish at protocol n when the better-trained ridge extracts the same information from ordinary statistics (the F-070 designed-ω case) |
| **arm** | (from clinical trials) | one complete training run inside a comparison, differing from the others by exactly one thing — as in a drug trial's "treatment arm" vs "placebo arm." The torus arm vs the GRU arm; the frozen arm vs the trained arm. An experiment = a set of arms run through identical scaffolding; our one-change-at-a-time rule says adjacent arms differ by a single variable |
| **zeroth-order / ES** | zeroth-order optimization / evolution strategies | training without gradients: perturb the parameters slightly in many random directions, evaluate the loss for each, and step toward the perturbations that helped. Hopeless at millions of params, practical at our 16 k physics params — the [F-021](../planning/issues/features/F-021-backprop-free-training.md) "task signal without backprop" rung |

## Losses & metrics

| Term | Stands for | Plain meaning |
|---|---|---|
| **L1 / mel-L1** | mean absolute error | a loss: the average of \|prediction − truth\| over every predicted number. Simple and robust — but when many outputs are equally valid, its best strategy is predicting the *median*, which blurs fine detail (why L1-only TTS sounds noisy: harmonics get averaged away). **mel-L1** = L1 over log-mel frames in Vocos's feature space, our K0 metric; "masked" means padded frames are excluded from the average |
| **CTC** | Connectionist Temporal Classification | the STT loss: lets the model emit characters at its own pace without per-letter timestamps, using a *blank* token for "still listening"; decode = collapse repeats, then drop blanks |
| **blank** | — | CTC's "no letter right now" token (our token id 0, shown as `-`) |
| **WER** | word error rate | fraction of words wrong (insertions+deletions+substitutions ÷ reference words); 0 = perfect |
| **CER** | character error rate | same but per letter; improves before WER does |
| **cased-WER** | — | WER computed *with* capitalization and punctuation counted — our extra-credit metric |
| **MOS** | mean opinion score | the industry-standard measure of speech quality: human listeners rate clips from 1 (bad) to 5 (excellent) and the ratings are averaged — the headline number in every TTS paper (real recordings score ~4.5). Needs a human panel, so it's slow and costly and reserved for decisive comparisons: the K2 blind A/B vs Kokoro is exactly a MOS-style test. CMOS is the side-by-side comparative variant |
| **UTMOS** | UTokyo-SaruLab MOS (predictor) | a neural network trained on datasets of human MOS ratings that *predicts* the score a panel would give — free, instant, no humans. The standard automatic quality proxy in modern TTS papers and leaderboards. Caveats: correlates strongly with humans at the system level but is noisier per clip, compresses near the top, and is trained mostly on 16 kHz English. Joins our eval battery at K1 (with the Vocos-roundtrip UTMOS measured as our ceiling); it matters most once a discriminator is in play, because adversarial training makes mel-L1 stop tracking quality |
| **MR-STFT** | multi-resolution short-time Fourier transform (loss) | compares generated vs real audio by their frequency recipes at three window sizes — short windows (32 ms) judge *timing* ("did the click land on the beat?"), long windows (128 ms) judge *pitch* ("is that an A or a B-flat?"); using all three stops the model gaming any single resolution. It is **phase-blind**: it checks *how much* of each frequency is present, not how the individual waves line up in time — two clips with identical recipes but misaligned waves score the same, which is why early generated audio has the right pitch/rhythm yet sounds metallic |
| **spectral convergence** | — | one half of MR-STFT: relative error of the frequency magnitudes |
| **F0** | fundamental frequency | voice pitch; we measure its shift to prove the speaker knob works in STS |
| **RTF** | real-time factor | processing time ÷ audio duration; 0.004 = 250× faster than real time |
| **TTFA** | time to first audio | latency before a TTS system emits its first sound; our target wedge (<50 ms) |
| **RNN-T / TDT** | (recurrent) transducer / token-and-duration transducer | stronger STT losses than CTC (no per-frame independence); the upgrade path NVIDIA's Parakeet took |
| **MCD** | mel-cepstral distortion | the standard "how far is this synthesized clip from the reference recording" number: distance between the two clips' mel-cepstra (a compact spectral-envelope description), in dB — lower is better, ~4–6 dB is typical good TTS. Deterministic and per-frame, so it localizes *where* in a clip the spectrum went wrong; core metric of [F-014](../planning/issues/features/completed/F-014-reference-audio-analysis.md) |
| **LSD** | log-spectral distance | average difference (in dB) between two clips' spectrograms, frame by frame — like MCD but on the raw spectrum instead of the compact cepstral summary. Its strength is the **per-band breakdown** (low/mid/high thirds in `analyze_audio.py`): "buzzy highs" vs "muddy lows" becomes a number — it's how we know the K0 quality gap is broadband rather than concentrated |
| **F0 RMSE** | F0 root-mean-square error | pitch-track error vs the reference, usually with a voicing-decision error rate alongside (did the model even voice the right frames?); the deterministic check on intonation — flat question contours show up here before a listener can name them |
| **PESQ / STOI** | perceptual evaluation of speech quality / short-time objective intelligibility | classic signal-level scores comparing degraded/generated audio to a time-aligned reference: PESQ predicts perceived quality, STOI predicts intelligibility. Built for telephony (strict alignment assumptions), so they suit copy-synthesis-style evals where our output tracks the reference frame-for-frame |

## Audio / DSP

| Term | Stands for | Plain meaning |
|---|---|---|
| **FFT / DFT** | (fast/discrete) Fourier transform | converts a signal into its frequency ingredients; how the torus computes its coupling |
| **STFT** | short-time Fourier transform | FFT applied to sliding windows → frequencies over time |
| **iSTFT** | inverse short-time Fourier transform | the reverse trip: frequency frames → waveform, by rendering each frame as a windowed slice of audio and overlap-adding. An "iSTFT head" (Vocos, Kokoro's generator, our K0-S2 plan) is a network that predicts STFT frames and lets this fixed, fast math do the final rendering — much cheaper than generating raw samples |
| **NSF source** | neural source-filter (excitation) | a vocoder design that copies how the voice works: an explicit *source* signal — harmonic sine waves at the predicted pitch (F0) for voiced sounds, noise for unvoiced — which the network then *filters* into speech. Handing the network a pitch-perfect excitation for free is why NSF vocoders (like Kokoro's 9-harmonic source) never drift off-pitch |
| **mel (spectrogram)** | — | STFT warped to match human hearing sensitivity; the model's audio input picture |
| **hop** | — | how far the analysis window slides each frame: 256 samples = 16 ms = one model step |
| **frame** | — | one 16 ms time-slice of features/output |
| **Hann window** | — | a smooth bell-shaped taper applied to each analysis/synthesis window |
| **OLA / COLA** | (constant) overlap-add | crossfading overlapping output windows so audio has no seams; Hann at 50% overlap sums exactly to 1 |
| **verbalization / text normalization** | — | the written-form → spoken-form pass that turns symbols into words before any vocab sees them: "£5.50" → "five pounds fifty", "5 kg" → "five kilograms", "x²" → "x squared". Contextual by nature (`-` = minus / range / hyphen; NASA said as a word, FBI spelled out). Runs before G2P, shared by char and phoneme modes ([F-015](../planning/issues/features/F-015-verbalizer.md)) |
| **ITN** | inverse text normalization | the reverse trip for STT output: "five pounds" → "£5", "three thirty" → "3:30" — same lexicons as verbalization, run backwards; future refiner-side work |
| **G2P** | grapheme-to-phoneme | the dictionary + rules layer that converts written text into sound symbols before the model sees it ("hello" → `HH AH0 L OW1`); ours is `g2p_en` (Apache-2.0, CMUdict + neural fallback, POS-aware for homographs like "record"). Costs well under 1 ms per sentence — invisible to TTFA |
| **phone / phoneme** | — | a **phone** is one concrete speech sound as actually uttered — the smallest audible segment ("cat" = K AE T, three phones). A **phoneme** is the abstract *category* a language treats as one sound (the /t/ in "top" and "stop" are different phones, same phoneme). ARPAbet symbols name them. MFA's "phones tier" is the utterance chopped into phones; a **per-phone span** is each phone's (start, end) timestamps — e.g. G: 0.10–0.18 s — which our F-009 duration targets convert to frame counts (span × 93.75 fps) |
| **ARPAbet** | — | the ASCII phoneme alphabet for English (39 phones; vowels carry stress digits: AH0 unstressed, AH1 primary, AH2 secondary). Our TTS input vocab (75 tokens = phones + stress variants + `. , ? !` + word boundary). Chosen over IPA because MFA's English alignment models speak ARPAbet natively — duration targets map 1:1 |
| **MFA** | Montreal Forced Aligner | the standard tool that takes (audio, transcript) and returns exact start/end times for every phone and word — "forced alignment." Source of F-009's ground-truth duration targets, including real pause lengths at punctuation |
| **quadrature** | — | measuring with both sin and cos so energy detection is phase-proof |
| **sample rate** | — | audio measurements per second; we run everything at 16 kHz |
| **PCM** | pulse-code modulation | plain uncompressed audio numbers, as in a `.wav` file |

## Architecture

| Term | Stands for | Plain meaning |
|---|---|---|
| **Kuramoto model** | — | the classic mathematics of coupled oscillators that synchronize; our latent core |
| **torus** | — | a grid whose edges wrap around (top↔bottom, left↔right) so waves never hit a wall |
| **phase angle (θ)** | — | the entire state of one oscillator: a single number in [0, 2π) giving its position in its cycle — the direction a stadium fan's phone light points as they windmill it at a concert ([the canonical picture](TRAINING.md#the-machine-itself-a-stadium-crowd-at-a-concert)). `sin θ, cos θ` are just the light's height and side position |
| **grid (G)** | — | the side length of one oscillator sheet: G=16 → 256 oscillators per sheet |
| **channel (C)** | — | one complete, independent G×G oscillator sheet with its own coupling kernel and natural frequencies; we run C=32 — like CNN feature maps, each free to specialize. Sheets mix only at the drive/readout projections, never inside the physics |
| **coupling kernel (K)** | — | NOT a GPU kernel: a G×G stencil of learned weights per channel — `K[dy,dx]` = how strongly an oscillator pulls on the one dy, dx away. Same rule everywhere on the torus ⇒ applying it is a convolution; think "the crowd's learned peer-influence stencil: how strongly each fan copies the fan (dy, dx) seats away" |
| **BTTB** | block-Toeplitz with Toeplitz blocks | matrix structure equivalent to "coupling depends only on relative position" — i.e., a circular convolution |
| **pinning / pacemaker** | — | our added `−λ·sin θ` term: couples every oscillator to a grounding reference, giving the stability that makes training possible. Technically Frenkel–Kontorova *substrate pinning*, **not viscous damping** (no −γ·θ̇ term) — the oscillator literature reserves "damping" for velocity friction, so our docs say *pinning*; the config flag keeps its historical name `--damping`, and older training logs use the old word |
| **spectral clamp** | — | a hard cap on the coupling kernel's amplification (for a circular convolution, exactly the max of its FFT magnitudes). Pinning stabilizes the *starting* physics, but training could grow the kernel until instability returns mid-run — the clamp makes that impossible by rescaling any channel that exceeds the cap |
| **order parameter (r)** | — | the standard 0-to-1 "how synchronized is this population" score from Kuramoto theory: average every fan's light direction as arrows and measure the resulting arrow's length — r=1 means every light points the same way (full sync), r≈0 means they're scattered (incoherence). Partial sync (a locked cluster + free riders) sits in between. **No input involved** — the crowd measured against itself (contrast PLV, which measures against a reference). Per-channel r over time is F-011's first diagnostic |
| **entrainment / phase locking** | — | an oscillator abandoning its own rhythm to rotate in step with a stimulus (or another oscillator). The gym's headline question: does training make the field entrain to input carriers? Measured per oscillator by **PLV** |
| **PLV** | phase-locking value | 0-to-1 score for one oscillator vs a REFERENCE: average the arrow `e^(i(θ−φ))` over time and take its length — it measures how steadily the oscillator holds its gap to the reference. Locked (even at a constant lag) → the gap holds → PLV ≈ 1; drifting → the gap winds around → PLV ≈ 0. The reference φ is the analytic stimulus phase when one exists (tones/vowels), or — the F-070 drive-phase reader — the per-band analytic phase of the drive actually delivered to the oscillator's row: **the gap between the input drive's phase and the oscillator's own movement**. In short: r = are the fans together; PLV = is this fan following its section's music |
| **Adler equation / Adler-type coupling** | — | the textbook forced-oscillator equation `θ̇ = ω + A·sin(φ_stim − θ)`: locking requires the forcing to *depend on the oscillator's own phase*. Our drive is **additive** (`θ̇ = ω + drive`, no θ-dependence), so a carrier cannot directly lock our oscillators — it only wiggles them. Discovered building the F-023 gym ([training log](../planning/experiments/08-10-2026-f023-gym-task1-run.md)); makes the *injection form* an architecture lever for F-022. The distinction resurfaced in F-020: pushing a *complex* oscillator's real axis (`z += dt·d`) is **Adler-type** — its phase effect is `−d·sinθ`, θ-dependent, pulling toward phase 0 in proportion to the input — while a tangential push (`ż += i·d·z`, our convention: `θ̇ += d` exactly) is not. Same input, two different physics; the SL core uses tangential so its A/B isolates amplitude alone, and the Adler-entry form is a recorded future arm |
| **frustration / phase lag (Sakaguchi α)** | — | the Sakaguchi coupling pulls each fan not toward exact alignment with a neighbor but toward alignment-MINUS-α — everyone wants to windmill a fixed angle ahead of their peers, which is globally unsatisfiable (all fans can't be ahead simultaneously). Borrowed from frustrated magnets (spin glasses: competing constraints that can't all be met); the perpetual compromise produces traveling waves and partially-coherent states instead of a frozen lock. NOT randomization — α is a fixed, deterministic lag. α = 0 is exactly Kuramoto; α → π/2 turns attraction sideways (chimera territory); our canonical untrained value is π/4 (B-003). **Unrelated to SL's α** (amplitude gain) — same letter, different model |
| **second-harmonic coupling (harmonic2 β)** | — | adds a sin(2Δ) term to the coupling (Δ = phase difference): the first harmonic sin(Δ) attracts only toward alignment (Δ=0), but sin(2Δ) attracts toward alignment AND toward opposition (Δ=π) — fans are happy either matched or exactly opposite, so the crowd can split into two counter-swinging clusters. "Harmonic" here is the Fourier order of the coupling FUNCTION, not an audio harmonic. β is the mixing weight: 0 = pure Kuramoto; 0.5 (our canonical untrained value) = visible but subdominant clustering pressure; ≥1 = clustering rivals alignment. **Unrelated to SL's β** (amplitude saturation) |
| **washboard potential** | — | the tilted-washboard picture of our pinning: `−λ·sinθ` carves a row of dips (the washboard), the natural frequency ω tilts it. `|ω| > λ` → the phase rolls downhill forever (rotates, ~0.014 cycles/frame at init); `|ω| < λ` → it sits trapped in a dip. The pinning barrier is exactly Eric's "binding limits oscillation" hypothesis, made concrete |
| **Shapiro steps / Arnold tongue** | — | how a *purely additive* AC drive can still lock a washboard oscillator: the nonlinear pinning term mediates it, but only inside narrow frequency windows (Arnold tongues) near the natural rate, with widths that follow a Bessel function of drive strength — stronger is not better (measured 08/10: gain 2 drags phase, gain 6 sits near the Bessel null and scrambles it). Named for the same effect in Josephson junctions |
| **DC / AC channels** | direct / alternating current (borrowed from electronics) | the two routes input energy takes into the field, per the speech-transduction 2×2 ([task-1 log](../planning/experiments/08-10-2026-f023-gym-task1-run.md)). **DC** = the steady level: loud input scrambles the pinning-bunched phases, so the field's average bunching is a slow, *silent*, inverted loudness meter (corr −0.9 at λ0.5 — the field's strongest input channel, carried by pinning). **AC** = the wiggle: oscillation at audio-band rates — the part sonification makes audible (corr ~+0.5). Stadium: DC is the crowd's average posture sagging when the music blares; AC is the swinging you can hear |
| **harmonic / octave transfer** | — | responding to a frequency's *relatives* (2f, f/2) and not just f itself. Candidate mechanism on record: pinning breaks rotational symmetry, so an element rotating at f emits harmonics into the coupling field, which 2f-tuned oscillators can resonate with — tested against the spillover null in [F-048](../planning/issues/features/F-048-octave-harmonic-transfer.md) |
| **impulse response / decay time τ** | — | poke the field once (one brief kick) and watch how long the disturbance takes to die out: run a poked and an unpoked twin from the same start, and τ is the half-life of their difference. Long τ = the field "rings." Ringing alone is not memory — that's exactly what [F-046](../planning/issues/features/F-046-lambda-memory-battery.md) separates |
| **memory capacity (delayed-input decoding)** | — | the honest test of *useful* memory, from the echo-state/reservoir literature (Jaeger): ask a probe to reconstruct the input from k frames ago using only the field's current state, for k = 1, 2, 3…; sum the scores over delays. Measures whether the past is still *readable*, not just still echoing |
| **Lyapunov exponent / contraction rate** | — | how fast two almost-identical copies of the field drift apart (positive = chaos, tiny differences explode) or pull back together (negative = contraction, differences fade). One number per dynamics setting, estimated by running twin fields ε apart. It bounds memory (differences fading = forgetting) AND training stability — B-001's gradient explosion is this rate compounded over the backprop horizon, which is why F-046 measures it per λ |
| **drive** | — | the external force pushed into the oscillator field each frame (from audio/text/speaker inputs) |
| **θ / state [C, G, G]** | phase field shape | the model's entire memory: one phase angle per oscillator, arranged as C=32 channels ("sheets") × a G×G=16×16 grid = 8,192 numbers. Persisted frame-to-frame within an utterance and across live-mic `step()` calls (it *is* what the model has heard so far); reset between utterances |
| **Euler step / substep** | — | the simplest way to simulate continuous physics on a computer: `new = old + dt × rate-of-change`, ticked in small increments. A *substep* means we tick the physics twice per 16 ms audio frame (finer, more accurate simulation) |
| **kick (drive kick)** | — | how far ONE simulation tick rotates an oscillator's arm, in radians: dt × gain × \|row value\| (the coach's shove per beat). The stop-motion physics is trustworthy only while kicks stay a small fraction of a turn — past π per tick the frames can't show which way the arm went (the wagon-wheel effect), which is the integrator-validity bound; rms ≤ ~0.5 rad is the accuracy comfort zone. The **kick instrument** (`drive_kick_stats`) stores rms/p99.9/max kick in every cell's results.json, so each result carries its own in-bounds proof (it edge-flagged carrier g=64 at max 3.15 ≈ π) |
| **tick** | — | one integration step of the simulation — the crowd advancing one frame. Always a *fraction* of an oscillation (stability caps dt·ω well under a full cycle; our safe band is ~0.01–1 rad/tick). For us ticks are **pegged to world time** (2 per 16 ms frame ⇒ one tick ≈ 8 ms of real audio); in settle-then-read models (Un-0/WONN) ticks are **dimensionless compute depth** — simulation rounds with no relation to any clock, like counting layers (see the [time-series FAQ](FAQ.md#what-does-time-series-mean-here--what-are-un-0-and-wonn-doing-differently-0813)) |
| **IMEX** | implicit-explicit (integrator) | a physics-stepping recipe that treats the *stiff, linear* parts of the dynamics implicitly (solve a tiny equation for the new value — unconditionally stable) and the nonlinear parts explicitly (plain Euler). LinOSS/D-LinOSS get their stability this way; for us, updating velocity first and reusing it (semi-implicit) plus dividing by `(1+Δt·γ)` for damping are one-line upgrades over pure explicit Euler ([08-10 deep-dive](../planning/research/08-10-2026-oscillator-theory-citations-deep-dive.md)) |
| **parallel scan** | associative scan | the trick that lets linear-recurrence models (S5, LinOSS, Mamba) train on all T timesteps in log₂T parallel rounds instead of T sequential ones — works only when each step is a *state-independent linear* map, which our sin coupling breaks. DEER/ELK extend it to nonlinear recurrences with diagonal structure; our coupling is diagonal *in Fourier space*, hence the parallel-in-time research idea |
| **Stuart-Landau oscillator** | — | the "next model up" from Kuramoto: each oscillator has an amplitude *and* a phase (one complex number z instead of one angle θ). Our Kuramoto core is exactly the all-amplitudes-equal slice of a Stuart-Landau grid — amplitude lets the readout encode *absence* of a feature, which pure sin/cos cannot. Implemented 08/11 (`resonant/core/stuart_landau.py`, F-020 arms B/C) |
| **Winfree model / WONN** | — | the 1967 *ancestor* of the Kuramoto model (Kuramoto is its simplification): coupling is not a function of the phase difference sin(θⱼ−θᵢ) but a product of two separate functions — the receiver's *sensitivity* ("at which points in my cycle am I receptive?") × the sender's *influence* ("at which points do I broadcast?") — closer to biological neurons and strictly more general. **WONN** ([Dai & Song 2026](https://arxiv.org/abs/2605.20922), ack #39) builds a vision network from these units and injects input by **setting the natural frequencies**: a trained encoder writes each oscillator's ω per example (telling each fan what tempo to windmill before the wave starts), where our drive adds force to phase velocity (shoving fans mid-wave). Both differences are tested in our substrate by [F-035](../planning/issues/features/F-035-winfree-coupling-arms.md) |
| **α, β (Stuart-Landau)** | amplitude gain / saturation | the two dials of an SL oscillator's loudness dynamics, `ṙ = α·r − β·r³`: **α** is the linear gain — how fast amplitude relaxes toward its resting value (our init 0.05: slow, near-critical, the SL-GNN "marginal stability" prior); **β** is the cubic saturation that stops runaway growth. Their *ratio* sets the resting radius r\* = √(α/β) — α is the **rate** dial, α/β the **radius** dial (a distinction F-020's original spec conflated; init β = α ⇒ r\* = 1, starting exactly on the phase core's unit-amplitude slice). Both per-channel and learnable in arm C |
| **Jacobian (products)** | — | each simulation step has a sensitivity matrix (its Jacobian): how much every output wiggles per input wiggle. Backpropagating through T frames multiplies T of these together — if each amplifies by just 1.02×, after 400 frames the product is ~2,800× (gradient explosion); if each shrinks, gradients vanish. Recurrent training lives on this knife's edge; our pinning keeps the multipliers just under 1 |
| **ridge (probe)** | ridge regression | the deliberately-weakest learner: one LINEAR scorer per class, weights fit in one closed-form matrix solve with an L2 penalty λ that shrinks them ("ridge" = the λI added down the matrix diagonal in (XᵀX+λI)⁻¹; the lam in results.json, validation-picked). Bolted onto a frozen system after the fact, gradient-free — a *probe*, not a head. What it measures: how much task information is LINEARLY READABLE in the field's featurized state — if a mere weighted checklist reads digits from the crowd's motion statistics, the dynamics put that structure there (the reader is too simple to compute anything itself). The floor = the identical ridge on frontend rows with the field bypassed, so cell − floor = what the dynamics added. Siblings: **frz** (frozen probe — even the readout direction is a fixed random draw) and the **trained-head** protocol (a learned classifier, the conventional-practice read) |
| **readout** | — | what we take out of the core each frame: sin and cos of every oscillator's phase |
| **FiLM** | feature-wise linear modulation | steering a network by scaling/shifting its features — how the speaker embedding controls STS |
| **d-vector** | — | a learned voice-fingerprint vector; the future zero-shot voice-cloning input |
| **PE** | positional encoding | injects word-order information into a transformer (without it, "hello" == "olleh") |
| **GRU** | gated recurrent unit | a battle-tested recurrent layer (1997-lineage, pre-transformer) that keeps a fixed-size memory vector and, at every frame, uses two learned "gates" — small networks outputting 0-to-1 values — to decide how much of the old memory to keep and how much of the new input to write over it. Like the torus it carries fixed-size state frame to frame, which is exactly why it's our TTS/STS control: same recurrent structure, no oscillator physics |
| **SSM** | state-space model | modern efficient recurrent layers (Mamba etc.); same fixed-size-state family as our torus |
| **GDN** | gated DeltaNet | a strong recent linear-recurrence layer; candidate long-context add-on and third baseline |
| **KV cache** | key-value cache | a transformer's memory, which *grows* with length — the thing our fixed-size state avoids |
| **FNO / SFNO** | (spherical) Fourier neural operator | published architecture family that learns kernels in frequency space — our core is mathematically a single-layer FNO with oscillator state |
| **substrate** | — | the medium computation runs *on* — the "stuff" doing the computing, as distinct from what's learned or what task is asked of it. Ours is the coupled-oscillator phase field; a transformer's is attention layers; a photonic reservoir's is light in a fiber; the brain's is neurons. "Same-substrate comparison" = same dynamical medium, different training (e.g. the gym's designed vs trained vs frozen ω arms) |
| **CFL condition** | Courant–Friedrichs–Lewy | stability speed-limit on simulation step size (relevant to the future soliton core) |
| **Fiedler value** | algebraic connectivity | the second-smallest eigenvalue of a graph's Laplacian matrix: 0 = the graph is disconnected, larger = harder to cut in two. A "Fiedler force" (Parzival's rule) is plasticity pressure keeping alive the bonds a graph needs to stay connected — relevant to free-form learned graphs; our weight-tied circulant coupling can't disconnect by construction (see the [FAQ](FAQ.md#hebbian-rules-vs-parzivals-coherence-entropy-and-fiedler-forces--and-what-homeostasis-means-for-our-model)) |
| **spectral entropy** | — | Shannon entropy of a spectrum's normalized energy: low = energy piled into a few modes, high = spread across many. As an F-011 diagnostic, measures whether training concentrates or spreads the coupling kernel's Fourier energy |
| **homeostasis** | — | biology's "return to the healthy operating point." Comes in two timescales: *unit-level fast* (how one element springs back after a perturbation — our pinning is this, in embryo) and *network-level slow* (plasticity rules keeping the wiring itself in a healthy regime — Parzival's entropy/Fiedler forces). See the [FAQ](FAQ.md#hebbian-rules-vs-parzivals-coherence-entropy-and-fiedler-forces--and-what-homeostasis-means-for-our-model) |

## Architecture families

The named schools of neural-network design, for reading
[COMPARISON.md](COMPARISON.md)'s architecture-family section. Ours is a **trained
oscillator field** — closest cousins are the recurrent/SSM families, with a
critical distinction from the reservoir family (see the
[FAQ](FAQ.md#are-we-actually-doing-reservoir-computing-esnlsm--how-do-we-know-the-physics-is-learning)).

| Term | Stands for | Plain meaning |
|---|---|---|
| **CNN** | convolutional neural network | slides small learned stencils ("filters") across the input, same weights at every position — great for patterns that can appear anywhere (edges in images, formants in spectrograms). Our coupling kernel is literally a convolution (one stencil per channel, applied everywhere on the torus via FFT) — but ours runs *inside a physics loop* rather than as a feed-forward stack |
| **RNN** | recurrent neural network | processes a sequence one step at a time, carrying a fixed-size memory vector forward — the same "loop with state" shape as our torus. Plain RNNs forget fast (gradients vanish/explode over long sequences); LSTM/[GRU](#architecture) added gates to fix that. Our pinning plays the same role the gates do: keeping the [Jacobian products](#architecture) tame |
| **transformer** | — | the architecture behind modern LLMs: every position *attends* to (looks at, with learned weighting) every other position at once. Trains fully in parallel, scales magnificently — but pays O(length²) compute and a [KV cache](#architecture) that grows with length, which is why streaming audio systems bolt streaming front/back-ends onto it rather than streaming through it |
| **attention** | — | the transformer's core move: for each position, compute "how relevant is every other position to me?", then take a weighted average. Content-based, order-agnostic (hence [PE](#architecture)) |
| **diffusion model** | — | generates by *iterative refinement*: start from pure noise, apply a network dozens of times, each pass removing a little noise until the output is clean. Highest sample quality in image/audio generation today; inherently many-pass, so latency-hostile for streaming (EchoTTS pays ~30–40 passes per chunk) |
| **flow matching** | — | the modern, simpler way to train a diffusion-style model: learn the *velocity field* that transports noise toward data along nearly-straight paths, then integrate it in a few steps with an ODE solver. What EchoTTS, Chatterbox's S3Gen, and F5-TTS use |
| **RWKV** | Receptance-Weighted Key-Value | a transformer/RNN hybrid: trains in parallel like a transformer but runs at inference as an RNN with a fixed-size state — no KV cache. Same "constant-memory streaming" promise as our torus, achieved with learned decay rules instead of physics |
| **reservoir computing** | — | the umbrella term for ESN + LSM: drive a large **fixed, random** dynamical system with your input and train **only a linear readout** on its rich internal echoes. Dirt-cheap to train (one linear regression), but the dynamics themselves never learn — the reservoir is a lottery ticket you hope is rich enough |
| **ESN** | echo state network | the classic rate-based reservoir (Jaeger 2001): a big random recurrent tanh network, weights frozen, spectral radius tuned so inputs echo but fade (the *echo state property* — the ESN ancestor of our pinning/spectral-clamp stability condition). Only the readout is trained |
| **LSM** | liquid state machine | the spiking twin of the ESN (Maass 2002, from neuroscience): a random *spiking* neuron circuit as the reservoir ("liquid" — inputs perturb it like stones dropped in water), readout trained on snapshots of the ripples |
| **SNN** | spiking neural network | neurons that communicate by discrete electrical events (spikes) in continuous time instead of numbers per layer — how biological brains work. Event-driven ⇒ near-zero energy when silent (neuromorphic chips like Intel Loihi). Hard to train (spikes aren't differentiable; *surrogate gradients* fake it); accuracy still trails non-spiking nets on most benchmarks |
| **liquid neural network (LTC/CfC)** | liquid time-constant | MIT's line of *trained* continuous-time ODE neurons whose time-constants adapt to the input (Hasani et al. 2021). Despite the name, **not** reservoir computing — everything is trained. Same "small trained continuous-time dynamical system" thesis as ours, with per-neuron ODEs instead of a spatially-coupled field |

**Patch (local order parameter / R_local)** — a small non-overlapping square
of oscillators inside one channel's grid (4×4 in F-054's macro features),
summarized by one number: the Kuramoto order parameter of just those
oscillators (0 = each doing its own thing, 1 = perfect unison). The region

## Mathematics used in the proofs

Terms from the Lean proofs in `proofs/` and Section 5 of the unified-theory notes. Where the proofs use a name of our own for a standard object, the standard name is given and ours is marked *(our name)*.

| Term | Stands for | Plain meaning |
|---|---|---|
| **complex number (z), Re, Im, \|z\|** | — | a number with two parts, `z = x + iy`, drawn as a point in the plane; `Re z = x` and `Im z = y` are its coordinates, `\|z\|` its distance from the origin and `arg z` its angle. One complex number carries one oscillator's whole Stuart–Landau state: `\|w\|` is the arm's reach (amplitude), `arg w` where the light points (phase); `\|w\|² = x² + y²` (Mathlib: `Complex.normSq`) |
| **complex conjugate (conj z, z̄)** | — | the same number with the sign of the imaginary part flipped, `x − iy`: the mirror image across the real axis. `conj(z)·z = \|z\|²`, which is why products of the form `Re(conj(wᵢ) wⱼ)` keep appearing: they measure how aligned two lights are |
| **conjugate transpose (Aᴴ, A\*)** | Hermitian transpose | flip a matrix across its diagonal and conjugate every entry. For real matrices it is just the transpose |
| **Hermitian (matrix)** | after Charles Hermite | a square complex matrix equal to its own conjugate transpose, `Kⱼᵢ = conj(Kᵢⱼ)`; for real entries this is simply **symmetric**, `Kⱼᵢ = Kᵢⱼ`. Stadium: fan `j`'s pull on fan `i` mirrors fan `i`'s pull on `j` (for complex weights, with the phase shift reversed). It is exactly the condition under which the crowd's motion is downhill on an energy landscape (P3); every learned directed stencil, and every connectome, breaks it, which is the content of the obstruction theorem |
| **matrix–vector product ((Kw)ᵢ)** | — | `(Kw)ᵢ = Σⱼ Kᵢⱼ wⱼ`: the total pull on fan `i` from every other fan, weighted by the stencil. For the torus kernel this sum is the convolution the FFT computes |
| **inner product (⟨a, v⟩)** | — | the generalised dot product: `Σᵢ conj(aᵢ) vᵢ` for complex vectors. Its real part, `⟨a, v⟩_ℝ = Σᵢ Re(conj(aᵢ) vᵢ)`, is the ordinary dot product once each complex number is read as two real coordinates; the proofs call the map `v ↦ ⟨a, v⟩_ℝ` `pairing a` *(our name)*, and "`g` is the gradient of `E`" is written as "the derivative of `E` is `pairing g`" |
| **norm (‖w‖, ℓ²)** | — | the length of a vector, `‖w‖ = √(Σᵢ \|wᵢ\|²)`; `‖w‖²` is the crowd's total swing energy (`sumNormSq` in the proofs) |
| **operator norm (‖K‖)** | — | the most a matrix can stretch any vector, `max ‖Kv‖/‖v‖`. The hypothesis `‖K‖ ≤ κ` in P5 is written out as `‖Kv‖² ≤ κ²‖v‖²` for all `v` (`OpNormBound`, *our name* for this standard bound). For a circulant kernel it equals the largest `\|Fourier coefficient\|`, which is what `resonant`'s [spectral clamp](#architecture) caps |
| **eigenvector / eigenvalue** | — | a vector that a matrix leaves pointing the same way, only scaled; the scale factor is the eigenvalue. Diagonalising a matrix means finding a full set of eigenvectors, in whose coordinates the matrix is just a list of scale factors |
| **unitary matrix** | — | a complex matrix whose conjugate transpose is its inverse (`W Wᴴ = 1`): a rotation of complex space that preserves lengths. The DFT matrix is unitary up to the factor `m` (`W Wᴴ = m·1`) |
| **circulant matrix** | — | a matrix whose entry depends only on the difference of its indices, `Kᵢⱼ = v(i − j)`: the same stencil at every position with wrap-around. Applying it is a circular convolution, and its eigenvectors are the Fourier modes, with the kernel's Fourier coefficients as eigenvalues (P6). The 2-D version on a grid is the [BTTB](#architecture) structure |
| **Fourier mode / DFT matrix** | discrete Fourier transform | the Fourier mode `k` on a ring of `m` seats is the pattern `j ↦ exp(2πi kj/m)`: the light direction advances by a fixed angle `2πk/m` per seat, a plane wave around the ring; on the torus the modes are products of a row wave and a column wave. The DFT of a kernel lists its coefficients on these modes (Mathlib: `ZMod.dft`), and the DFT matrix `W` has the modes as columns. In the language of group theory the modes are the **characters** of the group of positions, which is why one proof covers every wrap-around geometry |
| **block matrix** | — | a big matrix assembled from smaller ones, `[K₁ B; Bᴴ K₂]`: here the two modules' own stencils on the diagonal and the inter-module coupling off it (chaining) |
| **vector field (F)** | — | an arrow attached to every point of state space saying where the state moves next: `ẇ = F(w)`. Stadium: how every light is about to move, given where all lights are now |
| **gradient (∇E) / gradient field / potential** | — | the gradient of a function is the direction of steepest ascent, with length equal to the slope. A vector field is a *gradient field* (physics: *conservative*, with a *potential*) if it is the gradient of some function; then motion along `−∇E` is descent on the landscape `E`. P3 says the network's field is `−½∇E`; the obstruction says that without Hermitian `K` and a common tempo there is no such `E` at all |
| **gradient flow** | — | the dynamics `ẇ = −∇E(w)`: always downhill, as fast as the slope allows. The notes' "the real Ginzburg–Landau equation is a gradient flow" is this statement |
| **energy function / Lyapunov function** | after Aleksandr Lyapunov | a function of the state that never increases along the motion (`dE/dt ≤ 0`) and is bounded below. Its existence is what makes "the system settles" provable; the notes' `E` is one. The *Lyapunov exponent* ([Architecture](#architecture)) is a different notion from the same author: a growth rate, not a function |
| **equilibrium / fixed point / critical point** | — | an *equilibrium* (or *fixed point*) of the dynamics is a state where `F(w) = 0`, so nothing moves; a *critical point* of a function is where its gradient is zero (a flat spot: minimum, maximum or saddle). For a gradient flow the two coincide (`fderiv_energy_eq_zero_iff`). In the rotating frame a steadily windmilling crowd is an equilibrium |
| **Jacobian** | after Carl Jacobi | the matrix of all first partial derivatives of a vector field: entry `(i, j)` says how fast component `i` of the field changes when coordinate `j` of the state is nudged. It is the field's best linear approximation at a point ("linearisation"). Used here to show a field is *not* a gradient (a gradient's Jacobian must be symmetric); used in training as the per-step sensitivity whose products govern gradient explosion ([Jacobian (products)](#architecture)) |
| **Hessian** | after Otto Hesse | the matrix of all second derivatives of a scalar function: the curvature of the landscape in every pair of directions. It is the Jacobian of the gradient, hence symmetric. A critical point is **nondegenerate** when its Hessian is invertible (no perfectly flat direction); that is the hypothesis under which the implicit function theorem gives a smooth family of nearby equilibria |
| **symmetry of second derivatives** | Schwarz's (Clairaut's) theorem | for a twice-differentiable function, differentiating first in direction `a` then `b` gives the same as `b` then `a`: going east then north climbs the same as north then east. The single fact behind both the obstruction theorem and the equilibrium-propagation identity |
| **envelope theorem** | — | if `w(θ)` is always a critical point of `E(θ, ·)`, then `d/dθ E(θ, w(θ)) = ∂E/∂θ` evaluated at `w(θ)`: the indirect effect through the moving critical point vanishes because the slope there is zero. Why the nudged energy's derivative in the parameters is just `∂E/∂θ` in the equilibrium-propagation proof |
| **implicit function theorem** | — | if an equation `G(θ, w) = 0` holds at a point and `∂G/∂w` is invertible there, the equation can be solved for `w` as a smooth function of `θ` nearby. Gives the family of nudged equilibria `w(θ, β)` from the free one (Mathlib: `ContDiffAt.implicitFunction`) |
| **C¹, C², smooth** | continuously differentiable (once, twice) | how many times a function can be differentiated with a continuous result. Polynomials, hence our energies, are smooth (every order); a `C¹` family of equilibria is one that moves without kinks as the parameters move |
| **derivative in several variables (Fréchet derivative, `fderiv`)** | — | the linear map that best approximates a function near a point, the many-variable version of the slope; applying it to a direction `v` gives the directional derivative `dE(w)[v]`. In Mathlib `HasFDerivAt f f' x` says "`f` has derivative `f'` at `x`" |
| **Cauchy–Schwarz inequality** | — | `\|⟨a, b⟩\| ≤ ‖a‖‖b‖`: a dot product is at most the product of the lengths. Used three times in P5, including the form `(Σᵢ aᵢ)² ≤ N Σᵢ aᵢ²` |
| **power-mean (Jensen) inequality** | — | averages of powers beat powers of averages: `(S/N)³ ≤ (Σᵢ ρᵢ³)/N`, so `Σᵢ \|wᵢ\|⁶ ≥ S³/N²`. Why the quintic unit's restoring term wins in P5 |
| **bounded below** | — | a function whose values never fall under some floor. Needed for a Lyapunov function to force settling; for a polynomial potential it follows from a positive leading coefficient and degree ≥ 2 (a linear potential can be beaten by a strong coupling) |
| **absorbing ball / dissipativity / attractor** | — | a system is *dissipative* when every trajectory eventually enters a bounded region and never leaves: the *absorbing ball*. The *global attractor* is the set everything converges to, inside that ball. P5 proves the ball (an explicit radius beyond which the swing energy shrinks at a definite rate); the attractor needs an existence theory for solutions and is not formalised |
| **LaSalle's invariance principle** | — | the theorem that upgrades "`E` never increases and is bounded below" to "every trajectory converges to the set where `dE/dt = 0`", i.e. to the equilibria. The notes use it; Mathlib does not have it, so the proofs stop at its two inputs |
| **rotating frame / common frequency** | — | describing each light relative to a reference that turns at the crowd's shared tempo `ω`, `w = z e^(−iωt)`. In this frame a crowd windmilling in perfect unison looks frozen, so "settling" and "equilibrium" make sense; the energy exists only in such a frame, and only if every fan shares the tempo (residual frequencies `ωᵢ` break it) |
| **Wirtinger derivative (∂/∂w̄)** | after Wilhelm Wirtinger | a way of differentiating a real function of a complex variable, `∂/∂w̄ = ½(∂/∂x + i∂/∂y)`. The notes write the dynamics as `ẇ = −∂E/∂w̄`; the proofs write the same fact with the real gradient as `F = −½∇E`, the `½` being the one in the definition |

## Dynamical systems and oscillator physics

| Term | Stands for | Plain meaning |
|---|---|---|
| **bifurcation / bifurcation parameter** | — | a bifurcation is a qualitative change in a system's long-run behaviour as a dial is turned (a resting state becomes an oscillation, one state splits into two); the dial is the *bifurcation parameter*. Our threshold `μ` is one: the fan rests for `μ < 0` and windmills for `μ > 0` |
| **Hopf bifurcation** | after Eberhard Hopf | the specific bifurcation in which a resting state loses stability and a small oscillation is born, growing like `√μ` as the dial passes zero. The Stuart–Landau equation is its *normal form*: the simplest equation every system near a Hopf bifurcation reduces to, which is why the same unit appears in the cochlea, in lasers and in our network |
| **normal form** | — | the stripped-down canonical equation a whole class of systems looks like near a bifurcation, after a change of coordinates. Stuart–Landau is the Hopf normal form; "thresholds learned inside the Hopf normal form" means learning `μ` in this equation |
| **limit cycle** | — | an isolated closed orbit that nearby trajectories spiral onto: a self-sustained oscillation with a fixed amplitude, like a fan windmilling at a steady reach `√μ`. In the rotating frame it is a circle of equilibria |
| **supercritical / subcritical (Hopf)** | — | *supercritical*: the oscillation grows smoothly from zero amplitude as `μ` crosses zero (the Stuart–Landau unit, restoring force `−\|w\|²w`). *Subcritical*: the cubic term pushes outward (`+g\|w\|²w`) and only a quintic term `−s\|w\|⁴w` stops it, so the oscillation appears with a finite jump and coexists with the resting state over a range of `μ` |
| **bistable / hysteresis** | — | *bistable*: two stable states at the same dial setting (rest and a large oscillation), the system staying in whichever it was pushed into, a one-bit memory. *Hysteresis*: the switch up happens at a different dial value than the switch down. The subcritical unit is bistable, which is the reason to want it |
| **cubic / quintic (nonlinearity)** | third / fifth power | named for the power of the state in the restoring term: Stuart–Landau's `\|w\|²w` is cubic (degree 3 in `w`), the bistable unit's `\|w\|⁴w` is quintic (degree 5). In the potential `V(ρ)`, `ρ = \|w\|²`, these are the `ρ²` and `ρ³` terms |
| **on-site potential (V)** | — | the part of the energy that depends on one unit alone, through its amplitude: the spring law of a fan's arm. Stuart–Landau: `−μρ + ½ρ²`; bistable: `−μρ − (g/2)ρ² + (s/3)ρ³` |
| **compressive nonlinearity** | — | a response that grows slower than the input: at `μ = 0` a forcing `F` gives amplitude `F^{1/3}`, so faint inputs are amplified relative to loud ones. The hearing literature derives the cochlea's huge dynamic range from exactly this Hopf-normal-form fact (Eguíluz et al. 2000; Camalet et al. 2000) |
| **amplitude death** | — | coupled oscillators with different frequencies and strong coupling can all stop: every unit sits at `w = 0`. The amplitude-domain analogue of catastrophic phase lock (Mirollo & Strogatz 1990) and a candidate explanation for paper 02's accuracy loss at strong coupling |
| **Ginzburg–Landau equation** | — | the field (spatially continuous) version of Stuart–Landau; its *real* form is a gradient flow, the structure the notes' energy function inherits (Aranson & Kramer 2002) |
| **synchronisation transition / critical coupling (K_c)** | — | in a population with spread-out tempos, nothing locks until the coupling exceeds a threshold `K_c`, above which a growing fraction falls into step. For all-to-all Kuramoto with Lorentzian tempos of half-width `γ`, `K_c = 2γ` and the order parameter is `r = √(1 − K_c/K)` (P4; not formalised) |
| **Lorentzian distribution** | Cauchy distribution | a bell-shaped spread with heavy tails, `γ/(π(γ² + x²))`, `γ` the half-width; the tempo distribution for which Kuramoto's self-consistency equation can be solved in closed form |
| **Ott–Antonsen reduction** | — | the 2008 result that, for Kuramoto populations with Lorentzian tempos, the infinitely many phases obey one exact low-dimensional equation for the order parameter; the reason P4's formulas are exact in the infinite-population limit |
| **incoherence** | — | the regime where the lights point every which way, `r ≈ 0`; the opposite of locking |
| **mode locking (p:q)** | — | two rhythms with frequencies in a fixed ratio `p:q` (3 cycles of one per 2 of the other) that hold that ratio against perturbation; on the invariant torus of two coupled oscillators the locked orbit is a closed curve, the notes' reading of the transcript's "toroidal knot" |
| **quasiperiodic** | — | motion made of two or more rhythms whose frequencies are not in a rational ratio, so the pattern never exactly repeats; on the torus such an orbit winds forever without closing |
| **invariant torus / manifold** | — | a surface in state space that trajectories starting on it never leave (an *invariant set*); for two coupled oscillators each with a limit cycle, it is a doughnut (torus) of states, the stage on which locking and quasiperiodicity play out. Distinct from `resonant`'s wrap-around seating torus, which is a geometry of positions |
| **chimera state** | — | a population split into a locked, coherent part and an incoherent part at the same time, side by side; the patch-wise local order parameter is how one sees it |
| **criticality / self-tuned criticality / edge of chaos** | — | *criticality*: sitting exactly at a bifurcation (`μ = 0`), where response is largest and most sensitive. *Self-tuned criticality*: a feedback mechanism that keeps a unit there (Camalet et al. 2000, proposed for hair cells). *Edge of chaos*: the hypothesis, from reservoir computing, that computation is best just before dynamics turn chaotic; "capacity peaks at partial coherence" is this hypothesis for oscillators |
| **fading memory** | — | the property that the influence of long-past inputs dies out, so the state depends on recent history only; the precondition for the capacity bound |
| **information processing capacity** | Dambre et al. 2012 | a way of totalling how much of any function of the input history a linear readout can reconstruct from a system's state; the theorem says the total is at most the number of state variables `M`, however the system is built (P1; cited, not formalised) |
| **matched-M rule** | *(our term)* | compare networks at equal numbers of state variables `M` (not equal numbers of oscillators), equal FLOPs, equal readout width and equal trained parameters, because P1 ties the capacity ceiling to `M`. Our methodology, not a term from the literature |
| **soliton** | — | a localised wave that keeps its shape as it travels, because nonlinearity balances dispersion; a candidate "future core" in `resonant`, and the reason the CFL condition appears there |
| **excitability** | — | a unit that rests until a push crosses a threshold, then fires a large stereotyped response and returns to rest (a neuron's spike). Stuart–Landau lacks it, which is one argument in the notes for a third dimension in the unit |
| **Hodgkin–Huxley / FitzHugh–Nagumo** | — | the 1952 conductance-based equations for a neuron's spike (four variables, ion channels), and their 1961 two-variable caricature that keeps excitability and drops the biophysical detail. The standard excitable units a third dimension would be compared against |
| **central pattern generator / stomatogastric ganglion** | CPG / STG | a small neural circuit that produces a rhythm on its own (breathing, chewing, walking); the crab's stomatogastric ganglion is the best-mapped one, and Prinz, Bucher & Marder's 2004 parameter databases on it are the notes' example of gradient-free parameter search |
| **theta / gamma rhythms, cross-frequency coupling** | — | brain oscillations at ~4–8 Hz (theta) and ~30–100 Hz (gamma), named by their EEG frequency bands; *cross-frequency coupling* is one rhythm's phase controlling another's amplitude (gamma bursts riding on theta cycles). The notes' "theta damping / reset" means slow periodic modulation of `μ` or `K` |
| **ring attractor / grid cells** | — | a *ring attractor* is a network whose stable states form a circle, so it can hold one angle (a heading) indefinitely; *grid cells* are neurons firing on a hexagonal lattice of positions, modelled by attractor networks on a torus. Examples in the notes of nervous systems using the geometries we train |
| **connectome** | — | the complete wiring diagram of a nervous system (which neuron connects to which, with what strength); fully known for C. elegans and the fruit fly. Connectomes are directed and asymmetric, hence never Hermitian |
| **myelin** | — | the insulating sheath around long axons that speeds conduction; the transcript's "myelin gate" is read in the notes as sparse, distance-dependent inter-module coupling (the `B` of the chaining theorem) |
| **plasticity (Hebbian, STDP)** | spike-timing-dependent plasticity | *plasticity*: connection strengths changing with activity, the biological substrate of learning. *Hebbian*: "cells that fire together wire together", strengthen a link when both ends are active; for oscillators, "lock together, wire together" on phase differences. *STDP*: the timing-sensitive version, strengthening when the sender fires just before the receiver and weakening when after |
| **neuromorphic / oscillator Ising machine** | — | *neuromorphic*: hardware built to compute the way neurons do (event-driven, analog, in-memory). An *oscillator Ising machine* uses coupled oscillators' tendency to settle into a minimum-energy phase pattern to solve combinatorial optimisation problems; the "other use" of our physics |

## Learning rules without back-propagation

| Term | Stands for | Plain meaning |
|---|---|---|
| **energy-based model** | — | a model whose computation is "settle to the bottom of an energy landscape"; the output is read off the resting state. Hopfield networks (1982: a symmetric network that stores patterns as energy minima) are the classic case; P3 makes the oscillator network one |
| **local learning rule** | — | an update to a parameter that uses only quantities available at that parameter's own location (the two units a connection joins, or the one unit a threshold belongs to), as opposed to back-propagation, which routes error information from the output back through every layer. `∂E/∂μᵢ = −\|wᵢ\|²` is why the threshold rule is local |
| **equilibrium propagation (EqProp)** | Scellier & Bengio 2017 | a training method for energy-based models: let the network settle (the *free phase*), then settle again with the output gently pulled toward the target (the *nudged phase*, strength `β`), and update every parameter by the difference of `∂E/∂parameter` between the two phases divided by `β`. The theorem (proved here) is that as `β → 0` this equals the loss gradient, so a local measurement reproduces back-propagation's answer |
| **nudge (β) / free and nudged phase** | — | the nudge is the extra term `β·cost(w)` added to the energy that leans the network toward the right answer; the *free* equilibrium has `β = 0`, the *nudged* one `β > 0` |
| **contrastive Hebbian learning** | Movellan 1991 | EqProp's older cousin: a clamped phase (output forced to the target) and a free phase, with a Hebbian update on the difference; equivalent to back-propagation in the weak-feedback limit (Xie & Seung 2003) |
| **Jacobian homeostasis** | Laborieux & Zenke 2024 | a variant of EqProp that drops the requirement of symmetric weights by adding a term that keeps the network's Jacobian close to symmetric during training; the route the notes propose for directed (connectome-like) wiring |
| **holomorphic equilibrium propagation** | Laborieux & Zenke 2022 | a variant that makes the nudge complex-valued and oscillating, recovering the exact gradient from a single oscillation period instead of a `β → 0` limit; applicable here because the energy is polynomial |
| **deep equilibrium model / implicit differentiation** | Bai, Kolter & Koltun 2019 | a network defined as the fixed point of a layer applied repeatedly, trained by differentiating through the fixed-point condition (one linear solve) instead of through the iterations; the engineering twin of the implicit-function-theorem step in the EqProp proof |

## Interpretability (transformers)

| Term | Stands for | Plain meaning |
|---|---|---|
| **interpretability (mechanistic)** | — | the research programme of reverse-engineering what a trained network computes internally, circuit by circuit, rather than only measuring its outputs |
| **feature** | — | a direction in a layer's activation space that corresponds to an interpretable property of the input ("inside a quoted string", "about legal proceedings"); learned, not given, and not necessarily aligned with any single unit |
| **activation space** | — | the vector space of a layer's outputs: with `n` units, one point in `ℝⁿ` per input |
| **superposition** | Elhage et al. 2022 | the hypothesis that a layer represents many more features than it has units by assigning each feature a direction and packing the directions nearly, not exactly, at right angles, relying on features being sparse (few present at once) so the interference stays tolerable |
| **monosemantic / polysemantic** | — | *monosemantic*: one unit, one meaning, the readable ideal. *Polysemantic*: one unit responding to several unrelated properties, the rule in practice and the visible symptom of superposition |
| **sparse autoencoder (SAE) / dictionary learning** | — | train a much wider layer to reconstruct a layer's activations with a sparsity penalty, so each new latent captures one rarely-active direction; the current method for pulling features out of superposition (Bricken et al. 2023; Templeton et al. 2024). Caveat: the latents depend on the dictionary size and penalty |
| **residual stream** | — | in a transformer, the running vector each block reads from and adds to; features live as directions in it, with no coordinate owning a meaning |
| **MLP block** | multilayer perceptron | the transformer's per-position feed-forward sublayer (up-projection, nonlinearity, down-projection), usually four times wider than the residual stream |
| **probe (linear probe)** | — | a simple classifier (often ridge regression) fitted after the fact on a frozen system's states to test what information they contain; our [ridge probe](#architecture) is one |

## Formal verification (Lean)

| Term | Stands for | Plain meaning |
|---|---|---|
| **Lean (Lean 4)** | — | a programming language and *proof assistant*: a system in which mathematical statements are written formally and proofs are checked, step by step, by a small trusted program (the *kernel*). A theorem that compiles cannot be wrong about the statement it proves; what still needs human review is whether the statement says what we meant |
| **Mathlib** | — | the community library of formalised mathematics for Lean (calculus, linear algebra, Fourier analysis, the implicit function theorem…) that our proofs build on; pinned to a release in `proofs/lakefile.toml` |
| **Lake / elan** | — | *Lake* is Lean's build tool (`lake build` checks every proof); *elan* is its version manager, installing the Lean release a project's `lean-toolchain` file names |
| **theorem / lemma / hypothesis / conclusion** | — | a *theorem* is a proved statement; a *lemma* is a small theorem used on the way to a bigger one; the statement's *hypotheses* are what is assumed, its *conclusion* what follows. Reviewing a proof means reviewing the statement: are the hypotheses ones we accept, and is the conclusion the claim we care about? |
| **`sorry`** | — | Lean's placeholder for a missing proof; a file with a `sorry` compiles but proves nothing there. `proofs/` has none |
| **formalisation** | — | translating an informal mathematical claim into a precise Lean statement and proving it; the factor and sign conventions it forces are listed in `proofs/README.md` |
