# Design notes

The working notes behind paper 02's design, kept for reference. The paper itself is the design document: where these notes and the paper disagree, the paper and its code are right. They use the study's older vocabulary (tiers, gates, registration), which the paper and the code have since replaced with experiments named for what they test.

| file | what it holds |
|---|---|
| `DESIGN.md` | the study's design as it was drafted, with the dated decision log of every change to it |
| `TIERS.md` | the experiments as tiers, with their runs and costs |
| `audiomnist-prior-art.md` | published AudioMNIST and spoken-digit results by category, which are speaker-disjoint, which were verified, and which were left uncited and why |
